Context

An 11th-grade high school student is currently facing heavy burnout, balancing schoolwork, extracurricular competitions, tutoring, and personal life. Because the student has zero background in technology, the application must feature extreme simplicity, zero-friction input (natural language "brain dumps"), and a calming, supportive user experience (akin to a helpful senior mentor/kakak kelas).

As an AI-augmented developer, we will build this full-stack application leveraging a clean monorepo architecture (Node.js/Express backend + React/Tailwind frontend + LLM AI integration).

---

Architecture & Tech Stack

- Backend: Node.js, Express, TypeScript, Prisma ORM, SQLite, Zod validation, and AI API integration (Claude/Gemini).
- Frontend: React 18, Vite, TypeScript, Tailwind CSS, TanStack Query, Lucide icons.
- AI Engine: Structured prompt parsing to convert unstructured "brain dump" text into organized JSON tasks with micro-breakdowns and supportive feedback.

---

Implementation Steps

Phase 1: Database Schema & Backend Core Setup

- Define Prisma schema for Task (id, title, description, category [School, Competition, Tutoring, Personal], priority, status [Pending, InProgress, Done], dueDate, estimatedMinutes).
- Create REST API endpoints:
  - POST /api/tasks (Standard task creation)
  - POST /api/ai/brain-dump (Receives unstructured text, calls LLM, returns structured tasks and a motivational message)
  - GET /api/tasks & PATCH /api/tasks/:id

Phase 2: AI Brain Dump & Micro-Task Service

- Implement service layer using LLM integration.
- Prompt engineering to ensure:
  a. Extraction of distinct tasks from casual chat/rants.
  b. Automatic categorization and estimation of time.
  c. Breakdown of complex tasks (e.g., essays, project proposals) into 15-30 minute micro-tasks.
  d. Friendly, encouraging "kakak kelas" tone for feedback.

Phase 3: Frontend UI ("Zero-Friction" Design for Non-Tech Users)

- Home / Brain Dump View: A giant, welcoming text input box: "Lagi pusing apa hari ini? Tulis aja semuanya di sini..."
- War Room Dashboard: Clean, card-based view separating urgent school/competition items from personal rest time.
- Micro-Task Drawer: Clicking a task shows step-by-step small chunks so the student never feels overwhelmed.
- Sanity Meter / Encouragement Banner: Dynamic tips based on workload (e.g., reminding them to take a break if overloaded).

Phase 4: Polish & Deployment Prep

- Responsive mobile-first design (since high schoolers often check phones on the go).
- Local testing with npm run dev and verifying AI parsing accuracy.
- Easy access guide for the student.

---

Verification Plan

1. Backend Tests: Verify Prisma migration and API endpoints with unit/integration tests (npm test in backend).
2. AI Parsing Test: Send a messy sample prompt ("Besok tugas fisika numpuk, lusa proposal lomba, capek banget") to /api/ai/brain-dump and verify it returns structured JSON tasks + a supportive response.
3. Frontend E2E Test: Open the Vite frontend, type a brain dump into the main input, and verify tasks instantly render on the dashboard.
